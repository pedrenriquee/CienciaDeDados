#O que é big data e pq ele é importante para Machine learning

Big data é um conjunto de dados em larga escala.

Escala essa que pode ser em diferentes variedades como velocidade, volume, variedade e outros. 

A relação de big data com Machine Learning é que o aprendizado de máquina facilita a analise massiva quantidade de dados quando falamos em big data, ou seja, a relação entre os dois ramos é direta pois um gera dados que a outro processa.
